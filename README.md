# Slushie plugins for Claude

The official [Slushie](https://slushie.studio) plugin: it connects Claude to your Slushie content
studio so finished screens, product shots, demo videos and launch news go straight from where you
build into the right brand's vault. Slushie drafts the posts; you approve every one.

- Plugin: [`slushie/`](slushie/README.md)
- Connector (any MCP client): `https://slushie.studio/api/mcp`, setup at https://slushie.studio/connector

Install in Claude Code:

```
/plugin install slushie --marketplace Artefaktx/slushie-plugin
```
